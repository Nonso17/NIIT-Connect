# NIIT Student Platform

A Django-based web application designed for students to connect, share posts, manage profiles, and interact within a learning community.

## Features

- User Registration and Login
- Student Profiles
- Post Creation
- Dashboard
- User Search
- Authentication and Authorization
- Responsive Design

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Installation

git clone <repository-url>

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
